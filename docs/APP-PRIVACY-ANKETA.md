# Анкета App Privacy — что отвечать

Единственное, что осталось для отправки в App Store. Заполняется только
в веб-интерфейсе: в API этого раздела нет (сервер отвечает «маршрута не существует»).

## Путь

1. **appstoreconnect.apple.com** → войти
2. **Приложения** (My Apps) → **Magas Padel**
3. В левом столбце, ниже раздела с версией 1.0, пункт
   **«Конфиденциальность приложения»** (App Privacy)
4. Справа от **«Сбор данных»** (Data Collection) — кнопка
   **«Начать работу»** или **«Изменить»** (Get Started / Edit)

**ВНИМАНИЕ:** точные русские формулировки не проверены. В справке Apple
русской версии для App Store Connect нет, интерфейс переводится отдельно.
Английские названия приведены в скобках — по ним пункт находится точно.

## Что отвечать

**Первый вопрос:** собирает ли приложение данные?
→ **Да** (Yes, we collect data from this app)

Отвечать «нет» нельзя: при записи на корт приложение отправляет на сервер
клуба имя и телефон.

**Какие данные:** раздел **«Контактные данные»** (Contact Info) →
- **Имя** (Name)
- **Номер телефона** (Phone Number)

Больше ничего не отмечать: ни почты, ни адреса, ни геолокации,
ни идентификаторов, ни аналитики — приложение их не собирает.

**По каждому из двух пунктов дальше спросят три вещи:**

| Вопрос | Ответ |
|---|---|
| Используется для отслеживания? (Tracking) | **Нет** |
| Зачем используется? (Purposes) | **Работа приложения** (App Functionality) |
| Связано с личностью пользователя? (Linked to the user) | **Да** |

«Связано с личностью» — да, потому что по номеру телефона клуб находит
конкретного человека и его записи.

**В конце** — кнопка **«Опубликовать»** (Publish) вверху справа.
Без неё анкета сохранится черновиком и отправку не разблокирует.

## Почему именно так

Приложение работает без учётной записи. Имя и телефон человек вводит сам,
когда записывается, и они нужны ровно для одного: чтобы клуб знал, кого ждать,
и мог позвонить, если что-то изменится. Ни рекламы, ни аналитики, ни передачи
третьим лицам нет — это же написано в политике конфиденциальности:
https://padel.217-114-8-196.sslip.io/privacy.html

Ответы в анкете и текст политики согласованы. Если ответить «данные
не собираются», получится расхождение, а за это Apple снимает приложение
с проверки.

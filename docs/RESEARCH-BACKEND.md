# Beget: что подтверждено (цены на 2026-08-31)

Beget тарифицирует **посуточно**. Месячные суммы ниже — это ×30, арифметика, а не тариф.
Метки: **[П]** подтверждено на странице Beget, **[НП]** НЕ ПРОВЕРЕНО.

## Итог: Beget подходит. Два слабых места — бэкапы и внешняя сеть.

## 1. VPS — https://beget.com/ru/vps [П]

| CPU | RAM | Диск | ₽/сут | ≈₽/мес |
|---|---|---|---|---|
| 1 | 1 ГБ | 10 ГБ NVMe | 11 | 330 |
| 2 | 2 ГБ | 30 ГБ NVMe | 27 | 810 |
| **2** | **4 ГБ** | **40 ГБ NVMe** | **33** | **990** |
| 4 | 6 ГБ | 80 ГБ NVMe | 68 | 2 040 |
| 8 | 16 ГБ | 220 ГБ NVMe | 183 | 5 490 |

- **Root-доступ есть**, KVM. **Docker есть** как образ маркетплейса. Ubuntu 26.04/24.04, CentOS.
- Регионы: **Россия (Санкт-Петербург)** и Казахстан. ЦОД уровня Tier III на территории РФ.
- **[НП] Противоречие в официальных источниках по каналу:** страница VPS говорит 1 Гбит/с,
  база знаний — 250 Мбит/с. Не разрешено.
- **[НП] IPv6** нигде не упомянут.

## 2. Управляемые БД — https://beget.com/ru/cloud/dbaas [П]

Только **MySQL и PostgreSQL**. PostgreSQL максимум **16.4** (17/18 нет).
**Managed Redis / MongoDB / ClickHouse отсутствуют.**

| CPU | RAM | Диск | ₽/сут | ≈₽/мес |
|---|---|---|---|---|
| 2 | 2 ГБ | 20 ГБ | 33 | 990 |
| 2 | 4 ГБ | 40 ГБ | 45 | 1 350 |
| 4 | 8 ГБ | 80 ГБ | 102 | 3 060 |

**Жёсткие ограничения управляемого PostgreSQL [П]:**
- **Нет superuser.** Нельзя менять конфиг сервера, нельзя `CREATE DATABASE`.
- **Расширения ставятся только через тикет в поддержку.** Для нас это существенно:
  `btree_gist` нужен для exclusion-constraint, который на уровне БД физически запрещает
  пересечение двух броней на одном корте. Это наша главная защита от двойной брони.
- Масштабирование **только вверх**, вниз нельзя.
- Бэкапы «не реже одного раза в три дня». **[НП] Глубина хранения не опубликована. PITR не описан.**
  Восстановление затирает всю БД целиком.

## 3. Объектное хранилище S3 — https://beget.com/ru/cloud/storage [П]

**Хорошая часть Beget.** Ceph, совместимо с AWS S3 API (aws-cli, rclone, Cyberduck работают).
- **0,07 ₽ за ГБ в сутки ≈ 2,1 ₽/ГБ в месяц.** Запросы бесплатны, трафик безлимитный, канал 350 Мбит/с.
- Endpoint `s3.ru1.storage.beget.cloud`. Presigned-ссылки до 7 суток, CORS, свой домен, HTTPS.
- Лимиты: 100 бакетов, 5 ГБ на загрузку, 50 ТБ на объект, 2000 запросов/с.
- **Создание бакета только через панель или Terraform**, `aws s3api create-bucket` не поддерживается.

## 4. Что брать НЕ надо [П]
- **Managed Kubernetes** — отказоустойчивый control plane 102 ₽/сут ≈ 3060 ₽/мес, дороже всего
  остального стека вместе взятого. Для 7 площадок это абсурд.
- **Shared-хостинг** (420–790 ₽/мес) — нет постоянного процесса, API там жить не может.
- **Container Registry у Beget отсутствует.** Их официальный ответ — поднимать Harbor самому.

## 5. Бэкапы — читать внимательно [П]
Автоматические бэкапы VPS: бесплатные, **раз в 2–5 суток, хранятся около 10 дней**, и дословно
«частота и количество зависят от загруженности системы бэкапов». https://beget.com/ru/news/2019/vps-backup

**Это не SLA, это «как получится».** Для базы с бронями недопустимо.
→ **Обязательно свой `pg_dump` по cron в S3 со своей политикой хранения.**

## 6. Сеть наружу — главный риск проекта

**[П] `api.telegram.org` не работает из российских дата-центров в 2026.**
Подтверждено несколькими независимыми источниками: ICMP проходит, **TCP/443 в таймаут**,
при этом GitHub и Let's Encrypt с того же хоста доступны. Это DPI-фильтрация, а не блокировка по IP.
- https://habr.com/ru/sandbox/288226/
- https://vc.ru/id5779154/2795944-blokirovka-telegram-api-v-rossii
- https://qna.habr.com/q/1409730

**[НП] APNs (`api.push.apple.com`) и FCM (`fcm.googleapis.com`) с Beget — доказательств нет ни за,
ни против.** Ни документации, ни достоверных отчётов. Учитывая, что диапазоны Telegram уже режут
из российских ЦОД, это реальный риск.

→ **ОБЯЗАТЕЛЬНЫЙ ШАГ ПЕРЕД НАПИСАНИЕМ КОДА ПУШЕЙ.** Beget тарифицирует посуточно, проверка
стоит ~11 ₽:
```
for h in api.push.apple.com:443 api.push.apple.com:2197 \
         fcm.googleapis.com:443 oauth2.googleapis.com:443 \
         api.telegram.org:443; do
  timeout 5 bash -c "</dev/tcp/${h%:*}/${h#*:}" && echo "OK   $h" || echo "FAIL $h"
done
```
`oauth2.googleapis.com` тоже критичен — FCM HTTP v1 без токена Google не отправит ничего.

**[П] Docker Hub блокирует российские IP с 2024-05-30.** У Beget есть зеркало
`https://dockerhub1.beget.com`, прописывается в `/etc/docker/daemon.json`.

**[П] Beget блокирует порты реактивно.** В отзыве 2023 года поддержка пишет: «вынуждены
заблокировать порты 443 на исходящие и все входящие UDP до решения проблемы» после жалоб на абузы.
Исходящий 443 договором не гарантирован.

## 7. 152-ФЗ [П] / [НП]
Beget декларирует соответствие 152-ФЗ и приказам ФСТЭК №17 и №21, выдаёт акт оценки эффективности
и сертификат соответствия. https://beget.com/ru/cloud/152fz
**[НП] Какой уровень защищённости (УЗ-1…УЗ-4) и какие услуги входят в аттестованный периметр —
не указано. Цена не опубликована, только через отдел продаж.**
→ **Нельзя считать, что обычный арендованный VPS находится внутри аттестованного периметра.**

## 8. Деплой [П]
- **Два REST API**: старый `api.beget.com` (60 запросов/мин) и современный https://developer.beget.com/
  с OpenAPI-спецификацией и клиентами на PHP, Python, Go. Управляет жизненным циклом VPS.
- **Официальный Terraform-провайдер** — `tf.beget.com/beget/beget`,
  https://github.com/LTD-Beget/terraform-provider-beget. Умеет VPS, снапшоты, **бакеты S3**,
  сети, IP, SSH-ключи. **Не умеет облачные БД, Kubernetes и DNS** — это руками.
- **CLI нет. Git-деплоя нет.** Рабочая схема: GitHub Actions → SSH/rsync → `docker compose up -d`.

## 9. Рекомендуемая конфигурация

**Вариант для старта ≈ 1 032 ₽/мес** — то, что я рекомендую:

| Компонент | Что | ≈₽/мес |
|---|---|---|
| Сервер приложения | VPS 2 CPU / 4 ГБ / 40 ГБ, Ubuntu 24.04, Docker Compose: API + nginx + **PostgreSQL** + Redis + админка | 990 |
| Картинки | S3, ~20 ГБ | ~42 |
| TLS, DNS | Let's Encrypt + DNS Beget | 0 |

**Почему свой PostgreSQL, а не управляемый:** управляемый не даёт superuser, ставит расширения
только через тикет (а нам нужен `btree_gist` против двойных броней), не имеет PITR, глубина
бэкапов не опубликована — и стоит вдвое дороже. Свой Postgres + ночной `pg_dump` в S3 со своей
политикой хранения на этом масштабе строго лучше.

**Вариант с управляемой БД ≈ 2 022 ₽/мес** — если позже операционная нагрузка станет реальной.

**Что брать управляемым:** S3 (действительно хорош, MinIO поднимать незачем), DNS, Let's Encrypt.
**Что поднимать самим:** API, PostgreSQL, Redis (управляемого нет), админка.

## 10. Архитектурное требование по пушам
Отправку пушей делать **отдельным модулем за интерфейсом**, с поддержкой прокси через
переменные окружения. Если DPI ударит по диапазонам Apple/Google так же, как ударил по Telegram,
мы подставляем реле за границей, не трогая бизнес-логику. Персональные данные при этом остаются
в РФ, наружу уходит только служебный трафик пушей.

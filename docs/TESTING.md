# Тестирование

Проверки гоняются по **выложенной веб-версии** приложения headless-браузером
на этом сервере. На машине заказчика ничего не открывается.

```bash
scripts/test.sh                                   # по адресу по умолчанию
APP_URL=https://пример/v1 scripts/test.sh         # по другому адресу
```

Четыре набора, все лежат в `scripts/tests/`:

| Набор | Что проверяет |
|---|---|
| `audit.js` | Каждый маршрут открывается, отдаёт осмысленный текст, не роняет ошибок в консоль. Включая неверные адреса: `/court` без площадки, `/tournament?id=zzz`, несуществующая страница |
| `flow2.js` | Сквозные сценарии: запись на час и на два, расчёт цены, подтверждение менеджером, отмена брони, запись на турнир и её отмена, увод слота с подбором замены, дневной и вечерний тариф, границы дня |
| `metrics.js` | Ширины 320, 375, 390, 430 pt: нет горизонтальной прокрутки, нет нажимаемых элементов мельче 28 pt |
| `a11y.js` | У всех кнопок есть имя для VoiceOver, клетки сетки подписаны, занятые помечены недоступными, выбранные озвучены как «выбрано» |

## Что было найдено и исправлено 2 сентября 2026

1. **Ошибка гидрации React #418** на экранах площадки, турнира, заявки и подтверждения.
   Статический экспорт рендерит страницу на сервере, где адресной строки ещё нет,
   и разметка расходилась с той, что рисует браузер. Добавлен хук `useHydrated`:
   до монтирования показывается нейтральный каркас. На устройстве этого этапа нет.
2. **Неизвестный адрес внутри приложения** отдавался как главная страница.
   nginx переключён на `/v1/+not-found.html`, добавлен русский экран «Такой страницы нет».
3. **Пустые экраны на неверных ссылках.** `/court` без площадки показывал только шапку,
   `/tournament` без турнира — пустоту, `/book` и `/sent` писали «undefined».
   Везде понятное объяснение и кнопка на главную.
4. **Заголовок маршрута турнира** был «tournament» — не был объявлен в навигаторе.
5. **Клетки сетки мельче нормы Apple.** Поля уплотнены: на 390 pt клетка стала 45 pt
   вместо 42, на 375 pt — 43 pt. На 320 pt остаётся 35 pt: семь колонок физически
   не помещаются шире. Это ниже рекомендованных 44 pt, но выше абсолютного минимума 28 pt.
   **Экран 320 pt — это iPhone SE первого поколения, он не получает свежие версии iOS.**
6. **Подзаголовок вводил в заблуждение.** «Свободно 5 из 6 площадок» считалось по первому
   часу, а читалось как про весь день. Теперь: сегодня — «сейчас свободно 5 из 6»,
   другой день — «свободно 58 часов за день».
7. **VoiceOver не сообщал о выборе.** React Native Web не выводит `aria-selected`
   для роли «кнопка», поэтому состояние названо словом прямо в подписи: «Корт 5, 20:00, выбрано».

## Чего эти проверки не покрывают

- **Поведение на настоящем устройстве.** Всё проверено в браузере на сервере.
  Жесты, вибрация, системные диалоги, переход в WhatsApp — **НЕ ПРОВЕРЕНО**.
- **Крупный шрифт и «увеличить контраст».** Настройки iOS не воспроизводятся в вебе.
- **Многопользовательские гонки.** Увод слота показан заглушкой на одном слоте;
  настоящая защита от двойной брони — ограничение в PostgreSQL, его ещё нет.
- **Данные.** Все цифры моковые, см. `docs/OPEN-QUESTIONS.md`.

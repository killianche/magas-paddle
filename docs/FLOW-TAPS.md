# Сокращение количества нажатий при записи

Задача заказчика: «сделать так, чтобы максимально минимальное количество кликов приходилось делать».

## Почему это вообще важно — не вкусовщина, а данные

Пользователи в отзывах **буквально считают нажатия** и уходят из-за них:

- *«Пять кликов на то, что раньше делалось одним в Playtomic»* — Padel Mates, 1★
- *«Часто требует нескольких кликов там, где Playtomic требует одного»* — Padel Mates, 1★
- *«Корт всего на 30 минут, чтобы забронировать два корта, нужно начинать всё заново»* — ClubSpark, 1★
- *«Если нужного корта нет, нужно несколько шагов назад»* — ClubSpark, 1★
- *«Раньше я бронировал минуты за две, теперь уходит 10–15»* — MATCHi
- *«Бывает, я не бронирую студию, потому что заранее ужасаюсь работе с этим приложением»* — Skedda

Источник — docs/RESEARCH-UX.md.

## Что было в версии 0.1 макетов

| Путь | Нажатий |
|---|---|
| Главный → корт → экран времени → слот → «Далее» → «Отправить» | **5** |
| Главный → «Вся сетка» → ячейка → «Записаться» → «Отправить» | **4** |

Уже лучше рынка, но не минимум.

## Что делаем в версии 0.2

### Приём 1. Ближайший свободный слот на главном экране — сам по себе кнопка
Сейчас в строке корта написано «Свободен сейчас 18:30». Делаем это **нажимаемым чипом**.
Тап по нему = слот выбран, сразу открывается подтверждение.

### Приём 2. Строка быстрой записи вверху
Над списком площадок — одна строка: **«Ближайшее свободное: Корт 1, сегодня 18:30, 3 000 ₽»**.
Один тап — и человек на экране подтверждения. Это путь для того, кто хочет «просто поиграть
сейчас», а таких большинство.

### Приём 3. Имя и телефон запоминаются
После первой записи имя и телефон подставляются автоматически. Второй раз человек не вводит
ничего — только проверяет и отправляет.

### Приём 4. Длительность по умолчанию
Подставляется та, которую человек выбирал в прошлый раз. Менять можно, но не обязательно.

## Итог: сколько нажатий станет

| Сценарий | Нажатий |
|---|---|
| **Повторный клиент, «хочу ближайшее»** | **2** — тап по строке быстрой записи, тап «Отправить» |
| **Повторный клиент, конкретный корт** | **2** — тап по чипу времени в строке корта, тап «Отправить» |
| Повторный клиент, конкретные дата и время | 4 |
| Первый раз (нужно ввести имя и телефон) | 2 тапа + ввод двух полей |

**Два нажатия — это физический минимум**, ниже которого опускаться нельзя: экран подтверждения
с ценой убирать нельзя. Причина — тёмный паттерн, зафиксированный у Playtomic:

> *«Случайно нажал на матч и был немедленно записан без какого-либо подтверждения
> и даже без информации о стоимости»*

Запись в один тап без подтверждения = случайные брони, звонки «я не записывался»
и потерянное доверие. Экран подтверждения остаётся.

## Чего НЕ делаем ради экономии кликов
- Не убираем цену перед подтверждением
- Не убираем правило отмены
- Не записываем по одному тапу без подтверждения
- Не прячем занятые слоты (человек должен видеть картину дня)

# API

Адрес: `https://padel.217-114-8-196.sslip.io/api`
Код: `server/api` — NestJS + Prisma, как в docs/STACK.md.
Работает в контейнере `magas-api`, наружу проходит только через nginx.

## Что умеет

| Метод | Путь | Зачем |
|---|---|---|
| GET | `/api/health` | жив ли сервис и отвечает ли база |
| GET | `/api/courts` | площадки с тарифами; выключенные не отдаются вовсе |
| GET | `/api/availability?date=ГГГГ-ММ-ДД` | сетка «часы × площадки»: статус, цена и сколько часов подряд свободно |
| GET | `/api/bookings?phone=` | записи человека |
| POST | `/api/bookings` | создать запись |
| DELETE | `/api/bookings/:id?phone=` | отменить |
| GET | `/api/tournaments?phone=` | турниры, занятые места, записан ли этот человек |
| POST | `/api/tournaments/:id/entries` | записаться на турнир |
| DELETE | `/api/tournaments/:id/entries?phone=` | отменить запись |

Входа нет, человек опознаётся по номеру телефона — так решено в DECISIONS.md.

## Двойная бронь

База не даёт создать пересекающуюся запись. API ловит ошибку PostgreSQL `23P01`
и отвечает **409** с готовой заменой:

```json
{ "code": "slot_taken", "message": "Это время только что заняли",
  "alternatives": { "sameTime": [ { "courtId": "c2", "courtName": "Корт 2" } ],
                    "later": { "courtId": "c1", "hour": 20 } } }
```

Проверено на живом сервере: первая бронь Корт 1 на 18:00–20:00 создалась за 9 000 ₽,
вторая на то же время отклонена, в ответ пришли Корты 2, 3, 4 и время 20:00.

## Цены

Хранятся в копейках. Считаются по часам: игра с 17:00 на два часа — это дневной
час плюс вечерний, а не два одинаковых.

## Данные

`server/sql/seed.sql` — **заглушки**, ровно те же значения, что были зашиты
в приложении. Заменяются на данные клуба (вопросы Q1–Q8, Q44).

## НЕ ДЕЛАТЬ, пока не закрыто — содержательное

Это важнее технических полей.

**1. В приложении выдуманные данные клуба.** Цены 3 000 / 4 500 ₽, часы 09:00–24:00,
названия площадок, фотографии чужих кортов. Человек скачает приложение реального
клуба и увидит неверные цены. Кроме риска отклонения по правилу 2.3 (точность
метаданных), это просто вводит людей в заблуждение.

**2. Заявка никуда не уходит.** Бэкенд не подключён: запись живёт в памяти телефона.
Человек «запишется», придёт к назначенному времени — а его никто не ждёт.
База с защитой от двойной брони уже поднята, но API между приложением и базой
ещё не написан.

**Порядок, при котором публикация имеет смысл:**
1. Написать API и подключить приложение к базе
2. Получить от клуба настоящие цены, часы, названия, фотографии
3. Проверить сквозной сценарий на живых данных
4. Тогда публиковать

До этого приложение можно показывать через TestFlight или веб-версию —
там понятно, что это проба.

# Секреты

Сюда кладётся **только** ключ App Store Connect для Padel Magas.

- `AuthKey.p8` — закрытый ключ, права `600`, в git не попадает.
- Ключ должен быть **индивидуальным** (сгенерирован пользователем с ролью App Manager,
  у которого доступ ограничен приложением Padel Magas), а не командным.
- Чужие ключи из соседних проектов сюда не копируются.

Проверено по документации Apple: командный ключ ограничить приложениями нельзя,
индивидуальный наследует доступ своего пользователя.

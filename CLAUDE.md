# Magas Padel — правила работы над проектом

## Продукт
Мобильное приложение (iOS → затем Android) для падел-центра **Magas Padel** (г. Магас, РФ).
6 падел-кортов + 1 мини-футбольное поле. Рынок — СНГ, язык интерфейса — русский.
Плюс веб-админка для менеджера (десктоп, не приложение).

## ГЛАВНОЕ ПРАВИЛО: не додумывать

**Запрещено гадать, домысливать и выдавать предположение за факт.**

Если по ходу работы нет знания, понимания или доступа — действовать строго так:

1. **Сначала проверить.** Подключить агентов / поиск / документацию и выяснить.
2. **Если проверить нельзя** (нужен доступ, ключ, решение бизнеса, вкус заказчика) —
   **остановиться и спросить**. Не выбирать «вероятный» вариант молча.
3. **Всё непроверенное помечать явно**: `НЕ ПРОВЕРЕНО` / `ВОПРОС К ЗАКАЗЧИКУ`.
   Никогда не писать непроверенное утверждение обычным тоном как факт.
4. **Никаких выдуманных данных.** Цены, часы работы, названия кортов, контакты,
   правила турниров — только от заказчика. В прототипе моковые данные помечать как моки.
5. **Никаких выдуманных API и версий.** Если не читал документацию — не использовать.
   Каждое техническое решение должно опираться на прочитанный источник.
6. **Не расширять и не сужать задачу молча.** Если часть задачи заблокирована —
   сделать всё остальное полностью и явно сказать, что не сделано и почему.

Ошибка от догадки стоит дороже, чем один вопрос.

## Открытые вопросы
Все нерешённые вопросы ведутся в [docs/OPEN-QUESTIONS.md](docs/OPEN-QUESTIONS.md).
Ничего не реализуется поверх открытого вопроса без ответа заказчика.

## Бренд
Логотип: щит, скрещённые ракетки, мяч. Цвета — тёмный/чёрный фон, зелёный,
лаймово-салатовый акцент. Точные HEX — см. docs/BRAND.md (после разбора логотипа).

## Рабочее окружение
Claude Code работает **только на VDS**. Никогда не открывать браузер, сайты Claude или
любые URL на макбуке заказчика. Всё, что нужно отрендерить или проверить визуально, —
headless-браузер на VDS. Ссылки на артефакты просто выдаются текстом, заказчик открывает сам.

## Контроль расхода контекста и сабагентов

- Не запускай сабагентов автоматически. Сначала работай сам.
- Запускай сабагента только для действительно независимой крупной ветки работы;
  для простых поисков, чтения файлов, проверки и мелких правок сабагенты запрещены.
- Не создавай фоновые, циклические или длительно работающие задачи без явного запроса.
- После получения результата сразу завершай сабагентов.
- По умолчанию максимум 2 сабагента одновременно. Больше — только с явного разрешения.
